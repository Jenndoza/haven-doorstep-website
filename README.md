## Publish
1. Create a new public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` directly to the root.
3. Open Settings → Pages.
4. Select Deploy from a branch → main → /(root).
5. Wait for the default GitHub Pages URL to work before connecting the custom domain.
